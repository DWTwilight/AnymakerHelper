# Anymaker Helper

[English](README.md) | 简体中文

一个用于辅助制作 [Anymaker] 载具的 Blender 插件。

需要 Blender 4.5 LTS。

## 功能

- **游戏内预览：** 用立方体、边桥接和面重建预览网格，导出前就能看到游戏里的实际效果。
  源对象上的 Mirror（镜像）修改器会被一并带到预览网格里，并且可以设置在每次退出编辑模式时
  自动重建预览网格。
- **存档导出：** 写出游戏读取的 `.meta` 与 `.data` JSON 文件，并在场景中生成标注，
  标出导出的每一个节点与面。
- **基于网格的建模：** 把视图网格设置为游戏的单位尺寸，让你直接在游戏使用的同一套
  网格上建模。
- **自动清理：** 把顶点吸附到各自的最近网格坐标，并把同一坐标的顶点合并，确保不会有
  两个节点导出到同一位置。预览和导出前都会先执行同样的清理。

更多内容见[使用方法](#使用方法)。

## 安装

从 GitHub 下载 ZIP 压缩包，然后在 Blender 中：

    编辑 > 首选项 > 插件 > 从磁盘安装

启用 **Anymaker Helper**。面板会出现在 3D 视图的侧边栏（<kbd>N</kbd>）里的
**Anymaker Helper** 选项卡下，仅在物体模式下可见。

## 使用方法

所有会改动几何体的按钮都只作用于面板 **Game Object**（游戏对象）字段中指定的对象，
而不是当前选中的对象。请先设置该字段。在该字段持有网格物体之前，三个几何按钮
均为灰色不可用。

| 按钮 | 作用 |
| --- | --- |
| Apply Grid Gap | 把视图网格间距设置为网格单位（默认 8 cm） |
| Snap To Grid Points | 把每个顶点移动到其抓取点上，并合并共用同一抓取点的顶点 |
| Generate Preview Mesh | 创建或替换游戏内预览网格：`{name}_AM_preview` |
| Export Save File | 写出 `<name>.meta` 与 `<name>.data` |

### 设置项

| 设置项 | 默认值 | 含义 |
| --- | --- | --- |
| Grid Unit Size | 0.08 m | 游戏的基础网格单位：决定顶点立方体尺寸、网格间距、吸附阈值与平面度容差 |
| Include Degenerate Faces | 关闭 | 保留零面积的面（见下文） |
| Preview Opacity | 1.0 | 预览网格材质的透明度 |
| Refresh Preview On Edit Mode | 关闭 | 在编辑模式下隐藏预览，退出编辑模式时重建 |

建议保持 `[Grid Unit Size]` 的默认值，以便与游戏保持一致。

**一般工作流程：**

1. 点击 `[Apply Grid Gap]` 调整网格设置。
2. 把 **Game Object** 设为你正在建模的网格物体。
3. 开始建模。**记得开启 `Snap (Grid)`（吸附到网格）以让顶点保持在网格上。**
4. 点击 `[Generate Preview Mesh]` 查看游戏内效果。
5. 预览满意后，点击 `[Export Save File]`。
6. 把导出的文件移动到 `C:\Users\{你的用户名}\AppData\Roaming\Anymaker\creations\`
   （Anymaker 默认存档目录），即可在游戏中测试。

`[Generate Preview Mesh]` 与 `[Export Save File]` 都会先使顶点吸附最近网格坐标，因此即使
网格从未清理过也能正确导出。两者都会修改网格数据，都可以用 <kbd>Ctrl</kbd>+<kbd>Z</kbd>
撤销。撤销无法移除导出已经写入的文件。

## 注意事项与限制

- 本插件主要由 AI 编写并整理文档，且经过人工审阅，因此很可能存在缺陷。非常欢迎
  提交修复的 Pull Request。
- 请让网格保持在 Blender Z 轴 0 以上。导出不会抬高模型，任何低于 0 的部分在游戏中都会
  位于地面之下。
- 建模时请保持网格吸附开启。吸附与合并会作用于网格当前的实际状态，本应分开但落在同一
  单元内的顶点会被焊接掉。
- 一次只能导出一个对象。暂不支持多物体的载具，预览也会忽略 Mirror 以外的修改器。
- 平面度检测衡量的是相对质心平面的偏差，而不是最佳拟合平面，因此严重扭曲的面也可能
  通过检测。请尽量避免这种情况。
- 插件对写出的文件没有撤销步骤，使用相同名字重复导出会覆盖上一次的 `.meta`
  与 `.data`。
