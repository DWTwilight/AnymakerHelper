# Anymaker Helper

[English](README.md) | 简体中文

一个用于辅助制作 [Anymaker] 载具的 Blender 插件。

需要 Blender 4.5 LTS。

## 功能

- **游戏内预览：** 用立方体、边桥接和面重建预览网格，导出前就能看到游戏里的实际效果。
  目标上的所有修改器都会先被烘焙，并且可以设置在每次退出编辑模式时自动重建预览网格。
- **双层面：** 把某个面的所有边都标记为锐边(Sharp Edge)，这个面就会被当作双层面。预览
  网格里会额外生成一个法线翻转的面，导出时也会写一个额外的面，让它在游戏中两面都可见。
- **窗户：** 把面指定给 `AM_Window_MAT` 材质即可标记为窗户。该材质会自动创建，透明度为
  20%；预览会对这些面使用窗户材质，导出时会为它们写入 `"type": "window"`。
  若目标原本没有任何材质，在进入或退出编辑模式时会添加一个 `AM_Default_MAT` 材质槽，
  避免窗户材质覆盖整个物体。
- **非平面扇形面：** 把一个顶点周围平面扇形的所有内部径向边都标记为缝。支持完整一圈的扇形
  和不完整的一扇形区域，最小是两个面共用一条缝边。预览会保留各个面的顶盖但省略内部缝边，
  导出时会写成一个非平面面，节点从扇形中心开始，再沿外边界排列。把该面的所有边界边标记为
  锐边，可以让它变成双层面。
- **手动四边形中心：** 每次预览都会创建 `{target}_Quad_Centers` 集合，为两面的非平面四边形
  放置可移动的空物体标记。把标记移动到任意一个缝边端点即可选择导出中心；无效标记会被删除，
  缺失的标记会在下次预览时重新创建。
- **存档导出：** 写出游戏读取的 `.meta` 与 `.data` JSON 文件，并在场景中生成标注，
  标出导出的每一个节点与面。
- **对象或集合目标：** 目标可以是单个网格物体，也可以是一个网格集合。集合会被烘焙并
  合并为单个载具，让由多个网格搭建的模型导出为一个整体。
- **基于网格的建模：** 把视图网格设置为游戏的单位尺寸，让你直接在游戏使用的同一套
  网格上建模。
- **自动清理：** 把顶点吸附到各自的最近网格坐标，并把同一坐标的顶点合并，确保不会有
  两个节点导出到同一位置。若顶点落在其他边上，会在该顶点处切分边；只用于延长直线的顶点
  会被溶解。镜像修改器留下的缝(Seam)若两侧面共面，也会被溶解。预览和导出都会执行同样的
  清理，且在烘焙修改器前后各执行一次。

更多内容见[使用方法](#使用方法)。

## 安装

从 GitHub 下载 ZIP 压缩包，然后在 Blender 中：

    编辑 > 首选项 > 插件 > 从磁盘安装

启用 **Anymaker Helper**。面板会出现在 3D 视图的侧边栏（<kbd>N</kbd>）里的
**Anymaker Helper** 选项卡下，仅在物体模式下可见。

## 使用方法

所有会改动几何体的按钮都只作用于面板中设置的目标，而不是当前选中的对象。目标可以是单个
网格物体（**Object**）或一个网格集合（**Collection**）。请先设置目标。在目标持有至少
一个网格物体之前，三个几何按钮均为灰色不可用。

| 按钮 | 作用 |
| --- | --- |
| Apply Grid Gap | 把视图网格间距设置为网格单位（默认 8 cm） |
| Snap To Grid Points | 把每个顶点移动到其抓取点上，合并共用同一抓取点的顶点，在落在边上的顶点处切分边，并溶解直线顶点 |
| Generate Preview Mesh | 创建或替换游戏内预览网格：`{name}_AM_preview` |
| Export Save File | 写出 `<name>.meta` 与 `<name>.data`；集合模式的弹窗中提供 `Include Hidden Objects` 选项 |

### 设置项

| 设置项 | 默认值 | 含义 |
| --- | --- | --- |
| Grid Unit Size | 0.08 m | 游戏的基础网格单位：决定顶点立方体尺寸、网格间距、吸附阈值与平面度容差 |
| Include Degenerate Faces | 关闭 | 保留零面积的面（见下文） |
| Preview Opacity | 1.0 | 预览网格材质的透明度 |
| Refresh Preview On Edit Mode | 关闭 | 在编辑模式下隐藏预览，退出编辑模式时重建 |
| Include Hidden In Preview | 关闭 | 生成集合预览网格时包含隐藏的物体 |

建议保持 `[Grid Unit Size]` 的默认值，以便与游戏保持一致。

**一般工作流程：**

1. 点击 `[Apply Grid Gap]` 调整网格设置。
2. 设置目标：**Object** 模式选择正在建模的网格，或 **Collection** 模式选择一个集合。
3. 开始建模。**记得开启 `Snap (Grid)`（吸附到网格）以让顶点保持在网格上。**
4. 点击 `[Generate Preview Mesh]` 查看游戏内效果。
5. 预览满意后，点击 `[Export Save File]`。
6. 把导出的文件移动到 `C:\Users\{你的用户名}\AppData\Roaming\Anymaker\creations\`
   （Anymaker 默认存档目录），即可在游戏中测试。

`[Generate Preview Mesh]` 与 `[Export Save File]` 都会先把目标吸附到网格、切分重叠的边、
溶解直线顶点、烘焙其修改器，再对烘焙后的结果重复一次，因此即使网格从未清理过也能正确预览与导出。两者都会修改网格数据，
都可以用 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销。撤销无法移除导出已经写入的文件。

## 注意事项与限制

- 本插件主要由 AI 编写并整理文档，且经过人工审阅，因此很可能存在缺陷。非常欢迎
  提交修复的 Pull Request。
- 请让网格保持在 Blender Z 轴 0 以上。导出不会抬高模型，任何低于 0 的部分在游戏中都会
  位于地面之下。
- 建模时请保持网格吸附开启。吸附与合并会作用于网格当前的实际状态，本应分开但落在同一
  单元内的顶点会被焊接掉。
- 一次只能导出一个目标。集合目标只读取一层，且仅其中的网格物体会参与：嵌套集合与非网格
  物体会被忽略，所有参与的网格会合并为单个载具。
- 平面度检测衡量的是相对质心平面的偏差，而不是最佳拟合平面，因此严重扭曲的面也可能
  通过检测。请尽量避免这种情况。
- 插件对写出的文件没有撤销步骤，使用相同名字重复导出会覆盖上一次的 `.meta`
  与 `.data`。
